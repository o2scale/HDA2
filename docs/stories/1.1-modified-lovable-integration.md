## Story
**As a** Developer,
**I want** to integrate my existing Lovable frontend with a new FastAPI backend in a monorepo structure,
**so that** I can leverage the rapid prototyping from Lovable while maintaining architectural integrity.

## Acceptance Criteria
1. ✅ Lovable frontend successfully migrated from HDA2-FE to /frontend folder
2. ✅ Backend initialized with FastAPI and health check endpoint
3. ✅ Frontend and backend communicate via API proxy configuration
4. ✅ Docker compose runs both services with hot reload
5. ✅ Environment variables aligned between Lovable and new structure
6. ✅ GitHub Actions workflow for monorepo (tests both frontend/backend)
7. ✅ Cloud infrastructure provisioned and connected
8. ✅ Deployment pipeline working for integrated application

## Tasks / Subtasks

### Phase 1: Prepare Integration Environment

- [ ] Backup and tag Lovable repository (AC: 1)

### Phase 2: Frontend Migration

- [ ] Migrate Lovable frontend (AC: 1, 5)
  - [ ] Copy entire HDA2-FE contents to /frontend folder
  - [ ] Review and document Lovable's package.json dependencies
  - [ ] Check if tech stack aligns with our specs:
    - React version (target: 19.1.0)
    - Vite configuration
    - TanStack Query (if used)
    - Tailwind CSS setup
    - Any additional libraries
  - [ ] Update paths in package.json scripts
  - [ ] Preserve Lovable's .env structure

- [ ] Align frontend configuration (AC: 3, 5)
  - [ ] Create /frontend/.env.local for local development
  - [ ] Map Lovable env vars to our standard names:
    ```
    VITE_API_URL=http://localhost:8000/api
    VITE_SUPABASE_URL=${SUPABASE_URL}
    VITE_SUPABASE_ANON_KEY=${SUPABASE_ANON_KEY}
    ```
  - [ ] Update API client to use VITE_API_URL
  - [ ] Configure Vite proxy for backend:
    ```javascript
    // vite.config.ts
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true
      }
    }
    ```

## Integration Commands

```bash
# 1. Clone Lovable frontend into monorepo
cd HDA2
cp -r ../HDA2-FE ./frontend

# 2. Install frontend dependencies
cd frontend
npm install

# 3. Test Lovable frontend still works
npm run dev

# 4. Setup backend
cd ../backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 5. Run integrated environment
cd ..
docker-compose up

# 6. Verify integration
curl http://localhost:8000/api/health
# Frontend at http://localhost:5173 should work
```

## Risk Mitigation

1. **Risk**: Lovable code incompatible with our stack

   - **Mitigation**: Comprehensive testing checklist, keep backup

3. **Risk**: Environment variable conflicts
   - **Mitigation**: Clear mapping documentation, use .env.local

4. **Risk**: Different React/library versions
   - **Mitigation**: Gradual upgrade path, compatibility testing
