# Story 1.9: Public Content Viewer

## Status
Draft

## Story
**As a** Content Consumer,
**I want** to view shared translated documents without logging in,
**so that** I can access published content easily.

## Acceptance Criteria
1. Public viewer page accessible via share links without authentication
2. Clean, distraction-free reading interface optimized for content consumption
3. Support for both source and translated text viewing
4. Mobile-responsive design for reading on all devices
5. Optional password protection for sensitive shared content
6. Analytics tracking for content views and engagement
7. Configurable viewer permissions (view only, download, print)
8. Branded viewer with tenant customization (future Epic 3 enhancement)

### Share Link Security
```python
class ShareLinkValidator:
    def validate_access(self, token: str, password: Optional[str] = None) -> ShareLink:
        # Load share link by token
        share_link = ShareLink.query.filter_by(token=token).first()
        
        if not share_link:
            raise HTTPException(404, "Share link not found")
        
        # Check expiration
        if share_link.expires_at < datetime.utcnow():
            raise HTTPException(410, "Share link has expired")
        
        # Check download limit
        if share_link.max_downloads and \
           share_link.download_count >= share_link.max_downloads:
            raise HTTPException(403, "Download limit exceeded")
        
        # Verify password if protected
        if share_link.password_hash:
            if not password:
                raise HTTPException(401, "Password required")
            if not verify_password(password, share_link.password_hash):
                raise HTTPException(401, "Invalid password")
        
        # Update view count
        share_link.view_count += 1
        db.session.commit()
        
        return share_link
```

### Analytics Tracking
```typescript
class ViewerAnalytics {
  private startTime: Date;
  private scrollDepth: number = 0;
  private engagementTime: number = 0;
  
  constructor(private shareToken: string) {
    this.startTime = new Date();
    this.initTracking();
  }
  
  initTracking() {
    // Track scroll depth
    window.addEventListener('scroll', debounce(() => {
      const scrollPercentage = 
        (window.scrollY + window.innerHeight) / document.body.scrollHeight;
      this.scrollDepth = Math.max(this.scrollDepth, scrollPercentage);
    }, 100));
    
    // Track engagement time
    let lastActiveTime = Date.now();
    ['mousemove', 'keydown', 'scroll', 'touchstart'].forEach(event => {
      window.addEventListener(event, () => {
        const now = Date.now();
        if (now - lastActiveTime > 1000) {
          this.engagementTime += now - lastActiveTime;
        }
        lastActiveTime = now;
      });
    });
    
    // Send analytics on page unload
    window.addEventListener('beforeunload', () => {
      this.sendAnalytics();
    });
  }
  
  async sendAnalytics() {
    const data = {
      shareToken: this.shareToken,
      viewDuration: Date.now() - this.startTime.getTime(),
      scrollDepth: this.scrollDepth,
      engagementTime: this.engagementTime,
      deviceType: this.getDeviceType(),
      timestamp: new Date().toISOString()
    };
    
    // Use sendBeacon for reliability
    navigator.sendBeacon('/api/public/analytics', JSON.stringify(data));
  }
}
```
