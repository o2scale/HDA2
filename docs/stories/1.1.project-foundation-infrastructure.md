      - "8000:8000"

      - DATABASE_URL=postgresql://user:pass@db:5432/translation_platform

### Coding Standards
From [Source: architecture/coding-standards.md]:
- Python: Black formatter (88 char lines), Ruff linter, mypy type checking
- TypeScript: ESLint with strict rules, Prettier formatting
- Git: Conventional commits, feature branches
- Testing: Minimum 80% coverage goal

### Testing Requirements
From [Source: architecture/coding-standards.md#Testing Standards]:
- Backend: pytest with async support, fixtures for database sessions
- Frontend: Vitest with React Testing Library
- Test files co-located with source files (*.test.ts, *_test.py)
- Unit tests for all services and utilities
- Integration tests for API endpoints

### Infrastructure Notes
Based on [Source: architecture/tech-stack.md#Infrastructure & Platform], we're using a Supabase-centric approach for MVP:
- **Supabase**: All-in-one platform for database (PostgreSQL 16.4), authentication, real-time, and storage
- **Upstash Redis**: Serverless Redis for caching and job queues
- **Vercel**: Frontend deployment with edge functions
- **Railway/Render**: Backend API deployment
This approach aligns with the cost projections starting at $75-85/month for MVP phase.

4. **vite.config.ts** - Vite build configuration
5. **.env.example** - Environment variables template
