# Story 1.5: Translation Editor Interface

## Status
Draft

## Story
**As a** Content Reviewer,
**I want** a side-by-side editor to review and correct extracted text and translations,
**so that** I can ensure accuracy before finalizing documents.

## Acceptance Criteria
1. Two-panel progressive editor: Source Text Editor → Translation Editor
2. Side-by-side comparison view with synchronized scrolling
3. Inline editing capabilities for both source and translated text
4. Real-time auto-save with conflict resolution
5. Highlighting for changes, untranslated terms, and low-confidence sections
6. Approval workflow with "Touched" → "Verified" states
7. Keyboard shortcuts for common editing actions
8. Mobile-responsive design for tablet review

### Auto-save Implementation
```typescript
// Debounced auto-save
const debouncedSave = useMemo(
  () => debounce(async (content) => {
    await api.saveEditorContent(documentId, content);
    setLastSaved(new Date());
  }, 30000),
  [documentId]
);

// Track changes
useEffect(() => {
  if (hasChanges) {
    debouncedSave({ sourceText, translatedText });
    localStorage.setItem(`draft_${documentId}`, JSON.stringify({
      sourceText,
      translatedText,
      timestamp: Date.now()
    }));
  }
}, [sourceText, translatedText]);
```

### Synchronized Scrolling
```typescript
const handleScroll = (source: 'left' | 'right', position: number) => {
  const ratio = position / (source === 'left' ? sourceHeight : translationHeight);
  const targetPosition = ratio * (source === 'left' ? translationHeight : sourceHeight);
  
  if (source === 'left') {
    rightPanelRef.current?.scrollTo(0, targetPosition);
  } else {
    leftPanelRef.current?.scrollTo(0, targetPosition);
  }
};
```
