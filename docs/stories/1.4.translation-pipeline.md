# Story 1.4: Translation Pipeline with Language Selection

## Status
Draft

## Story
**As a** User,
**I want** to translate extracted text between supported languages,
**so that** I can make content accessible in multiple languages.

## Acceptance Criteria
1. Support 6 languages: English, Hindi, Marathi, Bengali, Gujarati, German
2. Quick language switching without re-processing source documents
3. Maintain conceptual accuracy over literal translation
4. Handle mixed-language source documents
5. Translation using Vertex AI Gemini 2.5 Pro with custom prompts
6. Preserve formatting and structure during translation
7. Support glossary terms and untranslatable words
8. Real-time progress tracking for translation jobs

### Database Models
From [Source: architecture/data-models.md#Translation Models]:
```python
class Translation(Base):
    __tablename__ = 'translations'
    
    id = Column(UUID, primary_key=True)
    document_id = Column(UUID, ForeignKey('documents.id'))
    source_text = Column(Text)
    translated_text = Column(Text)
    source_language = Column(String(10))
    target_language = Column(String(10))
    glossary_id = Column(UUID, ForeignKey('glossaries.id'))
    confidence_score = Column(Float)
    processing_time = Column(Float)
    created_at = Column(DateTime, default=datetime.utcnow)

class Glossary(Base):
    __tablename__ = 'glossaries'
    
    id = Column(UUID, primary_key=True)
    tenant_id = Column(UUID, ForeignKey('tenants.id'))
    name = Column(String(255))
    source_language = Column(String(10))
    target_language = Column(String(10))
    terms = Column(JSONB)  # {"source": "target"} mapping
    untranslatable = Column(JSONB)  # List of terms to keep
    version = Column(Integer, default=1)
```

### Translation Pipeline Flow
1. User selects source and target languages
2. System loads extracted text from database
3. Glossary terms are loaded if configured
4. Text is segmented by language detection
5. Each segment is sent to Vertex AI
6. Responses are parsed and glossary applied
7. Structure is preserved in final output
8. Result saved to database with metadata

### Performance Optimization
- Cache common translations at phrase level
- Reuse translations for repeated content
- Batch API calls for efficiency
- Use translation memory for similar texts
- Pre-load glossaries in Redis

### Error Handling
- Invalid language pair: Show supported combinations
- Token limit exceeded: Split and process in chunks
- API failure: Retry with exponential backoff
- Low confidence: Flag for human review
- Glossary conflicts: Use priority rules
