## Title
As a System Administrator, I want to set up Google Cloud Platform and Vertex AI services so that the application can use Gemini 2.5 Pro for text extraction and translation capabilities.

## Description
This is a prerequisite story that must be completed before any other development can begin. It involves setting up the Google Cloud Platform account, enabling necessary APIs, creating service accounts, and configuring credentials for local development and production deployment.

## Acceptance Criteria

### 1. GCP Account Setup
- [ ] Google Cloud Platform account is created or accessed
- [ ] Billing account is configured with appropriate spending limits
- [ ] Project is created with meaningful name (e.g., "translation-platform-prod")
- [ ] Project ID is documented in environment variables

### 2. API Enablement
- [ ] Vertex AI API is enabled
- [ ] Cloud Resource Manager API is enabled
- [ ] IAM Service Account Credentials API is enabled
- [ ] Cloud Billing API is enabled (for cost monitoring)
- [ ] All API enablements are verified via GCP Console

### 3. Service Account Creation
- [ ] Service account created with name: "vertex-ai-translator"
- [ ] Appropriate IAM roles assigned:
  - `roles/aiplatform.user` (Vertex AI User)
  - `roles/aiplatform.serviceAgent` (Vertex AI Service Agent)
  - `roles/storage.objectViewer` (for model access)
- [ ] Service account key generated in JSON format

### 4. Credentials Configuration
- [ ] Service account JSON key downloaded securely
- [ ] JSON key file renamed to `vertex-ai-credentials.json`
- [ ] File added to `.gitignore` (verify it's already there)
- [ ] Credentials stored securely for production deployment

### 5. Environment Configuration
- [ ] `.env.example` file created with required variables:
  ```
  # Google Cloud / Vertex AI Configuration
  GCP_PROJECT_ID=your-project-id
  GCP_REGION=us-central1
  VERTEX_AI_LOCATION=us-central1
  VERTEX_AI_MODEL=gemini-2.5-pro-latest
  GOOGLE_APPLICATION_CREDENTIALS=./vertex-ai-credentials.json

  # Token Limits (for reference)
  VERTEX_AI_MAX_INPUT_TOKENS=1048576
  VERTEX_AI_MAX_OUTPUT_TOKENS=65536
  ```
- [ ] `.env` file created with actual values (not committed)
- [ ] Environment variables tested and validated

### 6. SDK Installation & Testing
- [ ] Python SDK installed: `pip install google-cloud-aiplatform>=1.38.0`
- [ ] Basic connection test script created and run:
  ```python
  # test_vertex_ai.py
  import os
  from google.cloud import aiplatform
  import vertexai
  from vertexai.generative_models import GenerativeModel

  # Initialize
  project_id = os.getenv('GCP_PROJECT_ID')
  location = os.getenv('VERTEX_AI_LOCATION')

  vertexai.init(project=project_id, location=location)

  # Test model access
  model = GenerativeModel("gemini-2.5-pro-latest")
  response = model.generate_content("Hello, Vertex AI!")
  print(f"Connection successful! Response: {response.text[:100]}...")
  ```
- [ ] Test script executes successfully
- [ ] Response confirms Vertex AI connectivity
